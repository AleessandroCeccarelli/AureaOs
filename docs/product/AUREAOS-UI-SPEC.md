# AureaOS UI Design Specification

This document describes the intended desktop user experience for AureaOS. It is written in simple, clear English so that designers, developers, contributors, and reviewers can understand the direction without needing deep technical knowledge.

The goal is simple: AureaOS should feel familiar to people who already use Windows or macOS, but it should still look and feel like AureaOS.

## 1. Core idea

AureaOS should be:

- familiar in the way it works
- comfortable for everyday use
- modern and polished
- easy to learn
- visually calm, clean, and premium
- distinct enough not to feel like a copy of another desktop

The system should help users get things done quickly, without forcing them to learn a strange or difficult interface.

## 2. Design goals

AureaOS should follow these principles:

- Familiar workflows first
- Clear and predictable interactions
- Strong readability and accessibility
- A premium but relaxed visual mood
- A desktop that feels modern, not crowded
- A unique identity that is simple and calm

## 3. The visual identity

AureaOS should feel like a modern desktop that is polished, friendly, and professional.

The visual direction is inspired by the clarity and softness of modern operating systems, but it should not be a direct copy of Windows or macOS.

### 3.1 Light theme

The light theme should feel bright, clean, and easy to read.

Suggested values:

- desktop background: soft pale blue-gray
- window background: white or very light off-white
- panels: translucent white or very light blue glass
- text: dark gray / near-black
- controls: near-black or dark blue-gray
- accent: soft light blue with a premium premium look

This should strongly resemble the feeling of Windows 11 light mode, but with a calmer and more refined feel.

### 3.2 Dark theme

The dark theme should be comfortable for night work and low-glare use.

Suggested values:

- desktop background: deep blue-gray
- window background: dark slate blue or near-black
- panels: semi-transparent dark glass
- text: soft white or very pale gray
- controls: light gray / pale blue
- accent: bright blue with a subtle gold accent for AureaOS identity

The dark mode should be comfortable and modern without feeling too harsh.

### 3.3 Accent color

The main accent should be a soft blue, close to modern Windows-like clarity, but not too cold.

Suggested accent palette:

- primary blue: soft light blue
- secondary blue: slightly deeper blue for active states
- warm accent: very subtle gold / amber for AureaOS personality

This warm accent should be used only where needed, not everywhere. It should help define the product identity without overpowering the interface.

## 4. Window and surface language

Windows should be clean, readable, and calm.

### 4.1 Window style

- white or near-white surfaces in light mode
- dark slate surfaces in dark mode
- soft border lines
- subtle shadow for depth
- rounded corners
- clear title bar and control layout

The goal is to keep windows easy to read and easy to trust.

### 4.2 Glass panels

AureaOS should use soft translucent surfaces in the shell, side panels, and floating UI elements.

This should feel like a modern desktop system with soft glass effects, similar to the style of Apple Liquid Glass, but with a more restrained and professional feel.

Important rule:

- glass should support readability
- it should not reduce legibility or create confusion

## 5. The desktop shell

The shell should be modern, practical, and familiar.

### 5.1 Main layout

The desktop should be composed of:

- a floating bottom dock
- a top or system bar for status items
- a launcher or app overview area
- windows that behave normally for desktop users
- quick settings panel for system actions

The system should feel stable and conventional, without feeling old or heavy.

## 6. The dock

The dock is a central part of the AureaOS desktop experience.

### 6.1 Design direction

- floating dock at the bottom of the screen
- semi-transparent or softly glass-like background
- modern and compact layout
- easy to see and easy to use
- quick access to favorite apps and active apps

### 6.2 Behavior

- the dock should remain mostly hidden when not needed
- it should appear when the mouse moves near the bottom edge
- it should disappear again when the user moves away
- it should be subtle and not take over the screen

### 6.3 Fullscreen behavior

When an application is in fullscreen mode, the dock should not interfere with the experience.

The dock should:

- stay visually detached from the fullscreen window
- appear only when needed
- hide quickly when not required
- feel like a helpful system feature, not a visual obstacle

This keeps the desktop clean and immersive while still being fast to use.

## 7. Left side of the dock

On the left side of the dock, there should be the AureaOS logo.

This should act as the main launcher symbol.

It should open the main AureaOS launcher or system dashboard and provide access to:

- apps
- search
- settings
- folders
- recent items
- system tools

This is the main entry point to the system, and it should feel deliberate and important.

## 8. Right side of the dock

On the right side of the dock, there should be system status and quick access items.

These include:

- time and date
- Wi-Fi or Ethernet status
- mounted disk status
- audio / volume
- battery or power info if relevant
- quick system status access

When the user clicks these items, a compact quick settings panel should appear.

This panel should behave like a modern system status panel and include:

- volume
- brightness
- Wi-Fi / network controls
- Bluetooth
- power profile
- themes
- accessibility options
- other common system toggles

## 9. Quick settings panel

This panel is important because it gives the system a modern and practical feel.

### 9.1 Style

The quick settings panel should:

- be compact and clear
- use soft glass surfaces
- be easy to read at a glance
- have large, visible controls
- feel fast and immediate

### 9.2 Content

Typical controls include:

- volume slider
- brightness slider
- Wi-Fi / network switching
- Bluetooth toggle
- dark mode / light mode switch
- accessibility controls
- power modes
- display settings
- sound output selection

The panel should be designed to feel like the system is helping the user, not forcing them into a complicated menu tree.

## 10. Launcher and application search

AureaOS needs a launcher that feels powerful but simple.

The launcher should support:

- app search
- file search
- quick access to system settings
- recent documents and recent apps
- folder shortcuts
- a fast way to open commonly used tools

The launcher should search across:

- installed apps
- settings
- files and folders
- system actions

It should feel fast, immediate, and reliable.

## 11. Familiar interaction model

AureaOS should respect common desktop expectations.

This includes:

- standard window controls
- common resize and maximize behavior
- clear focus states
- predictable file and app management
- simple and obvious actions

Users from Windows or macOS should be able to work without confusion.

At the same time, the system must not become a visual copy of another OS. The important part is the behavior and the feel, not a direct imitation.

## 12. Keyboard shortcuts

AureaOS should support a keyboard-first desktop experience, but without becoming hard to use for casual users.

Suggested keyboard shortcuts:

- Super / Windows key = launcher or app overview
- Alt + Tab = switch apps
- Alt + F4 = close window
- Ctrl + Alt + T = terminal
- Super + L = lock screen
- Super + E = file manager
- Super + S = search or quick access
- Super + Arrow keys = snap windows to sides
- Super + Shift + Arrow keys = move windows between monitors

These shortcuts should feel natural and familiar.

## 13. Window management

AureaOS should support desktop productivity patterns.

Suggested features:

- maximize
- restore
- snap left and right
- snap top and bottom
- move between workspaces or desktops
- easy drag-and-drop between monitors

Users should be able to organize work efficiently without needing a complicated system.

## 14. Accessibility

AureaOS should be designed with accessibility in mind from the beginning.

This includes:

- strong contrast
- readable text sizes
- visible focus styles
- high-clarity controls
- keyboard navigation support
- sound and motion that is not excessive

The interface should not require users to guess what something means.

## 15. Motion and polish

Motion should feel smooth and modern, not flashy.

The system should use:

- soft transitions
- gentle expansion and reveal effects
- controlled animations for panels and windows
- subtle glass motion when panels appear

The goal is to feel premium and elegant, not over-animated.

## 16. Product identity

AureaOS should be recognizably its own product.

The identity should come from:

- the warm and premium palette
- the glass and soft surface language
- the dock and launcher behavior
- the calm but confident productivity feel
- a coherent desktop rhythm across all system parts

It should not feel like a generic Linux theme or a clone of another platform.

## 17. Final design direction summary

AureaOS should be:

- familiar to Windows and macOS users
- comfortable for new Linux users
- elegant and modern
- quick to learn
- clean and readable
- visually polished and calm
- distinct and recognizable as AureaOS

The desktop should feel like a premium operating system made for work, exploration, and calm daily use.

## 18. Recommended next steps

The next steps should be:

1. define the final light and dark color tokens
2. finalize the dock design and motion rules
3. define the launcher structure and app search behavior
4. design the system quick settings panel
5. build the first prototype shell in Rust or UI tooling
6. test usability with real desktop workflows
7. refine the design until it feels simple, clear, and native

This is the right direction for AureaOS: familiar enough to welcome users, but strong enough to become its own desktop identity.
