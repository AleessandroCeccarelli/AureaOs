## Criterio di manutenzione

Le traduzioni devono conservare significato, vincoli, terminologia e stato effettivo dei documenti originali. Non devono introdurre nuove decisioni né trasformare funzionalità pianificate o sperimentali in funzionalità completate.

In caso di divergenza, il documento originale in inglese e il codice sorgente devono essere consultati e la differenza deve essere segnalata. Le modifiche sostanziali alle decisioni di progetto vanno riportate in entrambe le lingue.
