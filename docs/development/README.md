# Development Records

This directory contains the operational record of AureaOS development.

## Documents

- [Development log](DEVELOPMENT-LOG.md) — dated entries recording repository milestones, engineering decisions, validation results, known limitations, and next actions.
- [Project maintenance and audit handbook](../architecture/PROJECT-MAINTENANCE-AND-AUDIT.md) — operational inventory, architecture links, verified status, known risks, and grouped maintenance procedures.

## Recording rules

- Record only work that has actually been committed or verified.
- Link entries to commit IDs and CI runs whenever possible.
- Distinguish implemented behavior from prototypes, planned work, and unverified hardware behavior.
- Keep entries append-only. Correct mistakes with a dated clarification rather than silently rewriting project history.
- Keep detailed subsystem design in the relevant architecture documents; this log records what changed and why.
