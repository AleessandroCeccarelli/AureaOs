# AureaOS Original Sound Library — Review 0.1.0

These are original, procedurally synthesized sound effects created for AureaOS.
No Pixabay files, third-party recordings, samples, or existing operating-system
audio were used as source material. The cues use original note sequences,
oscillator mixtures, envelopes, and light synthesized noise.

## Format
- Ogg Vorbis
- 48 kHz, mono
- Short UI cues, normalized conservatively to a -3 dBFS peak ceiling

## Files
- `message-received.ogg` — incoming message
- `notification-soft.ogg` — quiet notification
- `notification-bell.ogg` — bell-like notification
- `notification-gentle.ogg` — gentle two-tone notice
- `notification-subtle.ogg` — very discreet ping
- `notification-system.ogg` — general system notice
- `notification-ping.ogg` — short double ping
- `action-confirmed.ogg` — confirmation
- `action-success.ogg` — successful completion
- `warning-attention.ogg` — warning requiring attention
- `error-alert.ogg` — error
- `ui-feedback.ogg` — tiny interface feedback
- `window-open.ogg` — window opening
- `window-close.ogg` — window closing
- `device-connected.ogg` — device connected
- `device-disconnected.ogg` — device disconnected
