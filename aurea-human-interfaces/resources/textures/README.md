# AureaOS Surface Textures

This collection contains lightweight reusable CSS treatments rather than raster texture packs.

## Current source

- `textures.css` — theme-aware grid, diagonal-line and glow treatments using semantic AureaOS variables.

## Rules

Apply textures only to non-text decorative surfaces. Keep them subtle, preserve contrast and ensure they remain optional. Test both themes and reduced-transparency settings. Shared colors belong in `../../design-system/tokens/index.css`; do not define a parallel palette here.
