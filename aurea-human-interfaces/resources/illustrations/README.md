# AureaOS Interface Illustrations

Original SVG illustrations for onboarding, empty states and explanatory system messages.

## Current inventory

- `connection-offline.svg`
- `empty-library.svg`
- `setup-complete.svg`

Illustrations are supportive artwork, not substitutes for labels, status text or accessible instructions. Keep text localizable in the interface rather than embedded in the SVG wherever practical.

Future additions should answer an identified product need, share the same visual language and include source dimensions, intended use, theme behavior and provenance.
