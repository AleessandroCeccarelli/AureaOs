# Asset Library

This directory contains the visual resources used by the AureaOS interface and product presentation. The goal is to keep visual content organized and clearly separated from the runtime system layer.

## Scope

This area includes:

- wallpapers
- textures and patterns
- illustrations and empty states
- background compositions
- decorative resources used by the desktop and system surfaces

## Folder structure

- `wallpapers/` — desktop wallpaper sets and their attribution notes
- `textures/` — subtle patterns, glass effects, and repeated surfaces
- `illustrations/` — decorative system illustrations and onboarding imagery
- `backgrounds/` — default background compositions and layered presentation art

## Design rules

- keep resources reusable and semantically grouped
- avoid embedding hard-coded app-specific colors into artwork
- prefer vector assets where practical
- always keep attribution or licensing information with the asset set when required

## Purpose

These resources should support the system identity without becoming the product itself. The interface must remain usable, coherent, and readable even when the assets are removed or replaced.
