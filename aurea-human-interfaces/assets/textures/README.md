# Textures

This directory contains reusable texture and surface treatments for AureaOS interfaces.

## Purpose

Textures support the desktop visual system by adding subtle depth and refinement without reducing readability.

Examples include:

- glass-like overlays
- subtle noise or grain patterns
- surface overlays for panels and dialogs
- soft gradients and layered backgrounds
- material patterns for a modern, premium feel

## Guidance

Texture treatments must stay subtle. They should support the design language rather than create visual clutter.

A good surface treatment should:

- improve separation between layers
- support the glass visual language
- remain readable under text and controls
- work in both light and dark themes
