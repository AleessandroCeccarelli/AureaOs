# Backgrounds

This directory contains reusable background compositions and layered visual surfaces for AureaOS.

## Purpose

Backgrounds support the system shell, desktop surfaces, and initial product presentation. They should provide atmosphere without reducing usability or readability.

## Typical usage

- desktop surfaces
- splash and welcome inspiration
- presentation scenes for product landing pages
- layered compositions that support the main theme colors

## Design rules

- backgrounds should be readable with system UI overlay elements
- avoid excessive contrast conflicts with window chrome
- maintain consistency with the AureaOS warm, polished visual language
- keep each background aligned with the product’s identity: familiar, calm, confident, modern
