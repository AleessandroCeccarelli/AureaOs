# Wallpapers

This directory contains desktop wallpaper sets and related attribution notes for AureaOS.

## Intended use

Wallpapers should reinforce the AureaOS identity without overwhelming the user interface or reducing legibility. They should support the desktop shell and system surfaces rather than dominate them.

## Requirements

Each wallpaper collection should include:

- source or author reference
- licensing or attribution note where applicable
- a short description of the intended use and mood
- a preview or sample naming convention

## Typical usage

- default lock screen background
- default desktop wallpaper
- alternate wallpapers for themes and personalisation
- seasonal or product presentation variants

## Design approach

AureaOS wallpapers should feel:

- grounded and elegant
- calm and premium
- modern without visual noise
- supportive of the system’s warm and readable color language
