# Illustrations

This directory contains decorative visual assets used for onboarding, empty states, system messages, and supportive interfaces.

## Role

Illustrations help the system feel human and approachable, but they should never replace clear text or accessible labels.

## Examples

- first-run onboarding visuals
- empty state artwork for settings or storage
- recovery and backup guidance illustrations
- success and warning illustrations
- system status and explanatory scenes

## Guidance

- keep the illustration language consistent with the AureaOS visual system
- avoid overusing bright, noisy visual patterns
- ensure illustrations remain readable and not overly decorative
- pair every illustration with clear text to keep accessibility strong
