# Prototypes

This area contains design experiments, mockups, and concept work for the AureaOS desktop experience.

## Purpose

The prototype layer is for validation before production implementation.

It may include:

- desktop shell concepts
- onboarding flows
- settings layouts
- login and session ideas
- application concept mockups
- exploratory interface patterns

## Rule

Prototypes should remain clearly separated from production UI assets and runtime code.

They are a design validation tool, not a final product commitment.

## Usage

Use this folder to test:

- information architecture
- visual hierarchy
- interaction flow
- spacing and layout patterns
- system consistency across apps

## Current prototypes

- [Aurea Desktop — Roma concept 02](2026-11-aurea-desktop-preview-02.html): interactive desktop preview with Fides, launcher, quick settings, and light/dark appearance. It reuses the canonical design tokens and is an exploration, not a production interface.
