# Cursor SVG Masters

The original cursor artwork uses a transparent 64 × 64 canvas. Monochrome cursors are white with a dark outline; `busy.svg` is multicolor and includes a continuous SVG rotation preview.

These SVG files are editable source masters, not runtime cursor theme files. Raster export, Xcursor packaging, hotspot metadata, animation frames and compositor integration are separate steps. See the parent [cursor theme specification](../README.md).
