# Cursor SVG Masters

The original cursor artwork uses a transparent 64 × 64 canvas. Twenty-six semantic cursor masters are provided in two palettes: `../source/` uses white fills with dark outlines, while `../source/dark/` uses dark fills with white outlines. The busy indicator retains its deliberate multicolor treatment and animation preview.

These SVG files are editable source masters, not runtime cursor theme files. Raster export, Xcursor packaging, hotspot metadata, animation frames and compositor integration are separate steps. See the parent [cursor theme specification](../README.md).
