# Human Interface Review Previews

Visual review exports generated from approved source assets and prototypes.

- `components/` — shared component states and compositions.
- `fonts/` — typography specimens and language coverage.
- `icons/` — application, system and folder icon grids.
- `themes/` — light/dark comparisons and contrast reviews.

Previews are review artifacts, not source-of-truth assets. Record source path, generation date and variant. Edit the source, never the preview, when changing artwork.
