# AureaOS Symbol Categories

Functional categories for organizing verified entries in the AureaOS semantic symbol catalog.

## Categories

### System and Settings
`settings`, `system-update`, `security`, `accessibility`

### Files and Documents
`folder`, `folder-open`, `document`, `document-open`, `document-save`, `drive`

### Applications and Windows
`app`, `app-grid`, `window`, `window-close`, `window-minimize`, `window-maximize`

### Connectivity and Devices
`network-wireless`, `network-wired`, `bluetooth`, `device`, `usb`

### Accessibility
`accessibility`, `contrast`, `hearing`, `text-size`, `keyboard`

### Notifications and Status
`notification`, `status-info`, `status-success`, `status-warning`, `status-error`

### Multimedia and Controls
`media-play`, `media-pause`, `media-stop`, `volume`, `brightness`

### Actions and Navigation
`add`, `remove`, `edit`, `delete`, `search`, `arrow-left`, `arrow-right`, `chevron-down`

## Rules

- Each verified entry has one primary category; optional tags may describe secondary uses.
- Categories describe function, not appearance.
- Reuse existing categories where practical.
- Examples are conceptual until mapped to exact source assets.
- The catalog covers AureaOS needs, not every upstream Fluent symbol. Add upstream assets only when justified by a real interface requirement.
