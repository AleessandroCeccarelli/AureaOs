# AureaOS Typography

This directory contains the type and font sources used by the AureaOS design system.

The system should rely on modern sans-serif fonts for the desktop and a clear monospaced family for terminal and developer workflows.

## Recommended font stack

### UI font

- Segoe UI Variable
- Segoe UI
- Inter
- SF Pro Display
- Helvetica Neue
- Arial
- sans-serif

### Monospace font

- Cascadia Code
- JetBrains Mono
- SFMono-Regular
- Consolas
- monospace

## Design intent

The type system should be:

- readable
- clean
- modern
- calm and premium
- consistent across shell, apps, and settings

## Usage

The desktop should prefer clear, highly readable typography over stylized or ornamental type. Typography should support productivity and comfort, especially for long sessions.
